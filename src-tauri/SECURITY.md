# 原生安全边界

只覆盖 Windows x64。原生宿主没有遥测、账号资料上传、剪贴板读取或远程凭据提取。

## 数据流

| 模块 | 读取与输出 | 限制 |
| --- | --- | --- |
| `line.rs` | `settings.json`（含 controller secret）；启动 CLI/桌面版/网页版 | 经 `identities::private` 写成本用户独占文件；secret 只写不读，界面只拿 `secret_set`；文件损坏时报错、不覆盖。启动前重新做线路检查，未通过不启动。CLI 子进程只注入 `HTTP_PROXY`/`HTTPS_PROXY`=专用端口与 `NO_PROXY`，移除 `ALL_PROXY`；不改系统代理和用户环境变量。桌面版经 MSIX 执行别名带 `--proxy-server` 启动，已在运行或找不到别名时拒绝。 |
| `mihomo/` | 只读 mihomo `/configs`、`/proxies`、`/connections`；经专用端口请求出口查询服务 | 不写 Clash 配置。读不到、超时、格式不对都不是通过；专用端口等于任一普通入站端口即拦住。出口查询服务会看到出口 IP，不发送本地文件、账号或密钥。 |
| `migrate.rs` | 旧数据目录 `local.proxy.ccbaga` | 只在新目录不存在、旧程序未运行时整份复制；旧目录只读；遇链接或特殊文件整体放弃；新文件按本用户独占权限重建。 |
| `windows.rs` / `windows_process.rs` | 当前用户 SID、文件所有权、时区/语言、精确程序与 MSIX 包族 | 进程参数只在原生层识别，不序列化；结束进程前重新核验 SID、程序、创建时间和 live handle。不枚举凭据管理器密码。 |
| `cleaner*.rs` | Claude 白名单元数据与配置 | 只服务身份切换；快照、所有权、规范路径、链接与进程状态核验；不扫描项目源码。 |
| `browser/` | 指纹浏览器资料、本机回环核验页 | 启动前过线路门禁并写入专用端口；回环服务只监听 127.0.0.1、随机令牌、限制请求大小与资源根目录。核验页另向 ipwho.is、ipapi.co 查询出口。 |
| `claude_cli.rs` + `scripts/claude-cli.ps1` | 用户确认的 CLI 卸载/重装 | 只修改已识别的 CLI 程序，保留配置、会话、技能和项目；Job Object 限定子进程树。 |

## 身份保险库

- 显示信息只读默认 `.claude.json` 中 `oauthAccount` 的名称、邮箱、组织白名单；令牌不送界面。
- SQLite 只存脱敏目录、保留选择和恢复状态；凭据与文件归档写入 BAGAID01 容器：tar + Zstandard（兼容旧 gzip）压缩，ring AES-256-GCM 认证加密，独立归档密钥。
- `key.bin`、数据库和归档都在本用户独占 DACL 的目录里；同用户程序和管理员不在防护范围内。
- 切换前先完整保存并验收当前账号，失败回滚；崩溃后从持久恢复状态继续。直接删除需独立确认，不新增备份；普通删除不是安全擦除。

## 验证边界

单元测试只用临时目录和虚构账号；界面测试用假命令；线路检查与连接核对另有真实 mihomo 内核 + 本地假上游的离线判卷台。真实 Clash 配置、TUN、桌面版行为与第三方服务需要在目标机器上验证，未执行的不记为通过。
